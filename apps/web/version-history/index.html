Version history.

The useful changes in every shipped ShoutOut update, newest first.

ShoutOut 0.1.10

Latest
  • Prevents false “thank you” or “thanks” endings after trailing silence while preserving words you actually spoke.
  • Makes casual cleanup more reliably lowercase and unpunctuated, including longer dictations.

ShoutOut 0.1.9

  • Input Monitoring setup now reliably opens System Settings when macOS needs manual approval.
  • Improves paste reliability in Claude and Discord.
  • Avoids protected-folder permission prompts caused by copied files or folders on the clipboard.

ShoutOut 0.1.8

  • Adds smoother crab recording animation with a color-matched boom mic and steadier edge placement.
  • Installs into your user Applications folder automatically when launched from the DMG.
  • Improves quiet or accidental recordings so low-information captures are dropped instead of pasting stray text.
  • Refines local language cleanup with compact History tracing, before/after text, and the selected writing tone.
  • Fixes settings toggles and context-aware paste polish around spacing and capitalization.

ShoutOut 0.1.7

  • Fixes Fn/Globe double-tap so hands-free recordings reliably continue after the second tap.
  • Prevents quick double-taps from turning into two short recordings.
  • Shows the hands-free recording state immediately after the second tap.

ShoutOut 0.1.6

  • Tightens local language cleanup so commands stay commands instead of becoming assistant-style offers or promises.
  • Preserves request details such as “me” and avoids dropping leading context like “the diff is.”
  • Adds safer quote handling: technical terms can be quoted when useful, while filler quote spam is rejected.
  • Expands local model smoke coverage for transcript-derived overreach cases.

ShoutOut 0.1.5

  • Improves local language cleanup with a more reliable cleanup model, stricter validation, and visible before/model/after History details.
  • Keeps casual cleanup casual while Normal and Formal remove unnecessary speech fillers.
  • Fixes short hold-to-record timing so the hold threshold is based on the actual key press.
  • Redacts legacy cleanup text from diagnostics and runtime logs.
  • Cleans retired local cleanup model caches after updating.

ShoutOut 0.1.4

  • Adds an advanced WhisperKit Large v3 Turbo model option for local benchmarking.
  • Clarifies the model picker so quality, Turbo, and Fast English choices are easier to compare.
  • Tightens casual cleanup around unnecessary filler while preserving meaningful uses of “like.”

ShoutOut 0.1.3

  • Adds local language-cleanup visibility in logs and History.
  • Improves cleanup of abandoned false starts.
  • Warms language cleanup in the background while keeping idle memory lower.
  • Tunes shortcut recording timing with a shorter initial hold and tighter double-press window.

ShoutOut 0.1.2

  • Local-first macOS dictation update.
  • Signed and notarized DMG release.

ShoutOut 0.1.1

  • Local-first macOS dictation update.
  • Code-signed DMG release.
