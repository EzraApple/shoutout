# ShoutOut 0.1.14: production formatter verification

The app now formats the safe output selected by the existing language pass. Normal/Formal get conservative capitalization; Casual fallback protects numeric punctuation and rejects otherwise accepted candidates that damage numeric tokens. Disabled cleanup and empty inputs bypass formatting. Model, prompts, generation settings, and the existing validator are unchanged.

## Fresh service run

500 calls through the production service using the current Llama 3.2 1B model: 141 private development dictations and 18 public tone controls in all three tones, plus 23 original smoke cases. All 23 smoke cases passed. The 59 reserved history cases remain unused. Raw history and outputs stay private.

| Tone | Saved baseline tone checks | Integrated tone checks | Integrated content checks |
| --- | ---: | ---: | ---: |
| Normal | 33/42 | 37/42 | 36/42 |
| Casual | 41/42 | 42/42 | 39/42 |
| Formal | 37/42 | 40/42 | 39/42 |

Normal's content score was 37/42 in the saved baseline. A fresh model candidate omitted “maybe” before final formatting, causing the one additional failure. Reconstructing the pre-format Normal/Formal text from recorded candidate/acceptance decisions confirms every formatting edit changes capitalization only and adds no content-check failures. Same-generation tone scores improve from 34 to 37 for Normal and 37 to 40 for Formal. Casual's content failures match the saved baseline; its numeric guard activated twice.

This is development-set validation, not a claim of perfect cleanup or a blind model comparison. Remaining errors include lost qualifiers, unresolved spoken corrections, and missing sentence endings. The patch does not try to repair these by guessing words or punctuation.

Median service-call latency was 259 ms (maximum 4.20 seconds). Prior paired replay measured formatter-only median 0.4 ms, maximum 14 ms; the fresh service run does not separately time formatting.

## Automated checks

- 159 XCTest tests and 20 Swift Testing tests passed, including nine formatter tests and six history-search tests.
- Formatter tests cover safe-result selection, disabled/empty bypasses, failure reasons, decimals/signs/versions/dates, repeated numbers, technical tokens, code fences, abbreviations, Unicode, and idempotence.
- Full Swift package debug build and website typecheck/build passed.
- Final full release suite: 292 checks passed. A pre-publication review also restored original-text fallback when Casual cleanup would erase all text; none of the 500 replay finals was empty, so this guard leaves those observations unchanged.
- Download-handler expectations were updated for the new release; static release checks pass.

Private evidence is archived under `Evaluations/release-0.1.14` in ShoutOut's local Application Support directory, including compiled source hashes, all observations, and tone scores. The preceding paired prototype experiment remains archived separately.
